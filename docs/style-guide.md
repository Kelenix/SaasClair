# Charte éditoriale

> S'applique à l'interface, aux emails, au site vitrine et à la documentation.

## Ton : clair, direct, rassurant

| Principe | Faire | Éviter |
|----------|-------|--------|
| Clair | « 3 clients risquent de partir. » | « 3 segments présentent un score de churn élevé. » |
| Direct | Le chiffre d'abord, l'action ensuite. Phrases courtes. | Introductions, adverbes, conditionnels inutiles |
| Rassurant | « Vous avez 10 jours pour les retenir. » | « Alerte critique ! Vous perdez des clients ! » |

## Vocabulaire

| Dire | Ne pas dire |
|------|-------------|
| clients, visiteurs, inscrits | utilisateurs actifs, leads, sessions |
| revenu mensuel | MRR (sauf documentation technique) |
| canal, provenance | source d'acquisition, attribution |
| ce qui a changé, l'étape qui perd le plus | événements, propriétés, segments |
| configuration | onboarding |

## Règles d'écriture

- Vouvoiement, toujours.
- Nombres en chiffres, euros après le nombre avec espace insécable (`1 750 €`), pourcentages
  avec espace (`7 %`).
- Pas de promesse non vérifiée (délais, garanties, fréquences d'envoi).
- Messages d'erreur : ce qui s'est passé, puis quoi faire. Jamais de code technique.
- Boutons : un verbe qui décrit le résultat (« Connecter Stripe », « Préparer un email de relance »).
- Titres : une phrase, majuscule au premier mot seulement.

## Documentation

- Orientée tâches : « Comment faire X », étapes numérotées, une action par étape.
- Chaque procédure se termine par « Vérifier ».
- Captures d'écran : l'image de production locale, compte de démonstration, jamais de données
  réelles de clients.
- Aucun secret dans un document : seulement où le trouver et où le coller.
