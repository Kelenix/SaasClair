# FAQ et dépannage

## Questions fréquentes

**Dois-je configurer quelque chose ?**
Non. Deux actions : coller une ligne de code et connecter Stripe. Le reste est automatique.

**Pouvez-vous modifier mon compte Stripe ?**
Non. L'accès est en lecture seule.

**Combien de temps avant les premiers résultats ?**
Les chiffres de revenu et de churn apparaissent dès la connexion de Stripe ; les premières
recommandations sous 24 heures.

**Que veut dire « couverture 91 % » ?**
91 % de vos clients sont reliés à leur provenance. Les autres sont arrivés avant l'installation du
script ou utilisent un bloqueur de publicité. Le taux monte seul avec les nouveaux clients.

**Les chiffres affichés sont-ils réels ?**
Dans cette version, les analyses du tableau de bord utilisent des données de démonstration
réalistes ; un bandeau le rappelle tant que la configuration n'est pas terminée. L'espace
administrateur, lui, lit les vraies données des comptes.

**Mes données sont-elles protégées ?**
Hébergement en Europe, visiteurs anonymisés par défaut, accès cloisonnés par compte au niveau de
la base, suppression du projet à tout moment depuis les Paramètres.

## Dépannage

| Problème | Solution |
|----------|----------|
| « En attente des premières visites… » ne passe pas au vert | Vérifiez que la ligne est bien dans toutes les pages (en-tête du site), puis visitez votre site |
| Je n'ai pas reçu l'email de confirmation | Regardez les courriers indésirables ; sinon, « Mot de passe oublié » renvoie un lien |
| « Continuer avec Google » affiche un message | La connexion Google n'est pas encore activée : utilisez l'email |
| Mon accès est « suspendu » | Écrivez à l'adresse de contact : vos données sont conservées |
| Une modification de l'administration n'apparaît pas sur le site | Rechargez la page ; si elle a été faite directement en base, refaites-la depuis l'administration |
| Le bandeau de cookies ne réapparaît pas | Pied de page › **Gérer les cookies** |
