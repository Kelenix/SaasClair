# Bien démarrer

Comptez **moins de 5 minutes**. Aucune compétence technique n'est nécessaire.

## 1. Créer son compte

1. Sur la page d'accueil, saisissez l'adresse de votre SaaS et cliquez sur **Analyser mon SaaS**.
2. Indiquez votre prénom, votre email professionnel et un mot de passe (8 caractères minimum),
   ou continuez avec **Google** ou **GitHub**.

![Inscription](captures/inscription.jpg)

**Vérifier** : vous arrivez sur l'étape « Votre SaaS », votre adresse déjà remplie.

## 2. Étape 0 — Votre SaaS

Cliquez sur **Analyser**. SaasClair parcourt votre site, coche les pages trouvées (inscription,
tarifs, paiement) et affiche un mini-audit : vitesse, référencement, technologies. Cliquez sur
**Continuer**.

![Étape « Votre SaaS »](captures/configuration.jpg)

## 3. Action 1 — Installer le script

1. Choisissez votre plateforme : code HTML, WordPress, Webflow, Shopify ou autre.
2. Cliquez sur **Copier** et collez la ligne comme indiqué.
3. Pas la main sur le site ? **Envoyer les instructions à mon développeur**.

Le voyant « En attente des premières visites… » passe au vert dès que le script est détecté.

## 4. Action 2 — Connecter Stripe

Cliquez sur **Connecter Stripe**. L'accès est **en lecture seule** : nous ne pouvons rien
modifier. Les clients, paiements et abonnements s'importent, puis SaasClair relie
automatiquement vos visiteurs à vos clients.

## 5. C'est terminé

« Vous n'avez plus rien à configurer. » Votre tableau de bord s'ouvre.

> Envie de voir avant de terminer ? Le lien **Explorer avec des données de démonstration** ouvre
> le tableau de bord à tout moment.

## Check-list

- [ ] Compte créé
- [ ] Adresse du site analysée
- [ ] Script installé et détecté
- [ ] Stripe connecté
- [ ] Premier coup d'œil à l'accueil « Santé de votre SaaS »
